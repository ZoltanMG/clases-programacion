git init                          - para inicializarlos repositorios nuevos en local
git status                        - No es obligatorio, pero le permite ver el estado de los cambios en el repositorios
git add .                         - (todos los archivos) para agregar al traking del commit
git add <nombre_archivo>          - (archivos especificos) para agregar al traking del commit
git commit -m "<mensaje>"         - Cración de commit con los elementos trackeados anteriormente
git push origin <rama>            - publicaria a github los cambios
git pull origin <rama>            - trae los cambios del repositorios
git branch <nombre_nueva_rama>    - crea una rama
git checkout <nombre_rama>        - cambiar entre ramas
git log                           - mostrar el historial de commits
